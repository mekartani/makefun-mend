mend: one zero-dependency CLI that applies AI-written edits in four formats — unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON text-editor tool calls — to a tree of files, to the SPEC.md contract: three-tier line matching, all-or-nothing writes.

## Run it

```sh
node main.ts [--format=unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
